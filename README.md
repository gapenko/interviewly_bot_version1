# Тренажёр технического собеседования (Telegram-бот)

Бот проводит тренировочное техническое собеседование по выбранному направлению: 15 вопросов
(опыт, технические, поведенческие), обратная связь после каждого ответа, итоговый разбор,
черновик резюме и Word-отчёт. Первые вопросы бесплатны, полный доступ оплачивается отдельно
для каждого направления (ЮKassa или Telegram Stars).

## Структура проекта

```
interview_bot/
├── main.py              # точка входа: middleware блокировок, обработчик ошибок, команды меню
├── config.py            # настройки из .env
├── storage.py           # данные в JSON (атомарная запись), пользователи, платежи, отзывы, промокоды
├── screen.py            # «чистый чат»: один экран бота, уведомления с кнопкой «Скрыть»
├── menus.py             # общие экраны: главное меню, выбор направления, правила, результаты
├── keyboards.py         # клавиатуры (на каждом экране есть путь назад)
├── ui_utils.py          # фразы интервьюера и подача вопросов
├── questions.py         # направления и банк вопросов
├── llm_service.py       # обращения к LLM: обратная связь, подсказки, отчёт, резюме, аудит
├── docx_service.py      # Word-отчёт
├── yookassa_service.py  # API ЮKassa
├── states.py            # FSM-состояния (только для режимов ввода текста)
└── handlers/
    ├── __init__.py      # порядок роутеров
    ├── admin.py         # панель администратора
    ├── payment.py       # оплата, промокоды, бонусы
    ├── reviews.py       # отзывы
    ├── resume.py        # «Мои результаты», черновик резюме, аудит резюме
    ├── interview.py     # собеседование
    └── start.py         # главное меню, помощь, поддержка, страховочные обработчики
```

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить значения
python main.py
```

## Переменные .env

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | — (обязательно) |
| `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` | доступ к LLM | — |
| `ADMIN_IDS` | ID администраторов через запятую | пусто |
| `ADMIN_SECRET_KEY` | пароль для `/auth`; если не задан — вход по паролю отключён | пусто |
| `AUTH_MAX_ATTEMPTS`, `AUTH_LOCK_MINUTES` | защита `/auth` от подбора | 5, 30 |
| `FREE_QUESTIONS_COUNT` | число бесплатных вопросов | 4 |
| `SBP_PRICE_RUB`, `ACCESS_PRICE_STARS` | цена доступа к направлению | 100, 50 |
| `BONUSES_PER_STAR` | сколько бонусов = 1 звезда скидки | 4 |
| `REFERRAL_BONUS_PER_INVITE`, `REFERRAL_FULL_ACCESS_THRESHOLD` | реферальная программа | 150, 600 |
| `SHOW_ANSWER_SCORE` | показывать оценку X/10 после каждого ответа (`1`) | 0 |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | ЮKassa | — |

## Данные

Все данные лежат в `data/` (в git не попадают): `users.json`, `payments_log.json`,
`processed_payments.json` (защита от повторного зачёта платежей, не очищается при сбросе
статистики), `reviews.json`, `promocodes.json`, `campaigns.json`, `admins.json`, `screens.json`
(ID текущего экрана в каждом чате), `archive/` (копии данных перед сбросом статистики).
