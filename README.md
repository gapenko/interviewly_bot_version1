# Interview Prep Bot

Telegram-бот для подготовки IT-специалистов к техническим собеседованиям.
Бот последовательно задаёт 10 вопросов (технические, поведенческие, про опыт),
анализирует каждый ответ через Anthropic API и в конце выдаёт итоговый отчёт
с оценками и рекомендациями. Первые 3 вопроса бесплатны, дальше — доступ
открывается через оплату Telegram Stars.

## Структура проекта

```
interview_bot/
├── main.py              # точка входа, запуск бота
├── config.py             # загрузка токенов и настроек из .env
├── states.py             # FSM-состояния диалога
├── questions.py          # список из 10 вопросов собеседования
├── storage.py             # работа с JSON-файлами (пользователи, платежи)
├── llm_service.py         # обращение к Anthropic API
├── handlers/
│   ├── __init__.py        # сборка роутеров
│   ├── start.py            # /start, /reset, показ вопроса
│   ├── interview.py        # приём ответов, анализ, итоговый отчёт
│   └── payment.py          # оплата через Telegram Stars
├── requirements.txt
└── .env.example
```

## Установка и запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните значения:

   ```bash
   cp .env.example .env
   ```

   - `BOT_TOKEN` — токен вашего бота, полученный у [@BotFather](https://t.me/BotFather).
   - `LLM_API_KEY` — ключ доступа к Anthropic API.
   - Приём платежей через Telegram Stars должен быть включён у бота
     в настройках @BotFather (Stars работают "из коробки", отдельный
     provider_token не требуется).

3. Запустите бота:

   ```bash
   python main.py
   ```

## Команды бота

- `/start` — начать (или продолжить) собеседование.
- `/pay` — открыть оплату доступа к полному собеседованию вручную.
- `/reset` — сбросить прогресс пользователя (полезно для тестирования).

## Хранение данных

Данные хранятся в двух JSON-файлах рядом с проектом (создаются автоматически):

- `users_data.json` — статус оплаты и прогресс каждого пользователя по вопросам.
- `payments_log.json` — отдельный лог всех успешных оплат (telegram_id,
  username, сумма в Stars, дата/время).

## Примечания

- Модель, указанная в `.env` (`LLM_MODEL`), должна быть валидным
  идентификатором актуальной модели Anthropic на момент запуска — сверьтесь
  с документацией Anthropic, если получаете ошибку о неизвестной модели.
- Бот перехватывает ошибки LLM API (лимиты, недоступность) и не падает —
  в случае сбоя пользователь получает уведомление и собеседование продолжается.
